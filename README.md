# SUNARC SOLUTIONS – Solar Energy Website

**Empowering Maharashtra with Sustainable Energy Infrastructure Solutions**

SUNARC SOLUTIONS is a responsive, modern business website designed to showcase solar energy services, projects, and company information. The website helps customers explore solar solutions and contact the company for inquiries.

## 🌞 About the Project

The website represents SUNARC SOLUTIONS, a solar energy solutions provider based in Pune, Maharashtra, India.

It features a modern design, responsive layouts, service information, project gallery, and contact functionality.

## 🚀 Features

- Modern and responsive user interface
- Home page with hero section
- About Us page
- Solar services showcase
- Project gallery
- Contact form with email integration
- Privacy Policy and Terms & Conditions pages
- Mobile-friendly navigation
- Font Awesome icons
- Solar-related images and visuals

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
- Font Awesome – Icons
- Google Fonts – Typography
- Unsplash – Illustrative solar images

## ▶️ How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using the **Live Server** extension.

Alternatively, open `index.html` directly in your browser.
